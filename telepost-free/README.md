# TelePoster Free — бесплатный автопостинг в Telegram-каналы

Бот для админов каналов: публикация сразу и **отложенные посты с премиум-эмодзи**, **ИИ-рерайт текста
на открытой модели Qwen3** (без платных API), **нейропостинг** (бот сам следит за чужими публичными каналами,
переписывает их новые посты нейросетью и публикует в ваши) и **автопересылка** между вашими каналами.
Монетизация — тариф Pro за Telegram Stars; всё базовое бесплатно.

## Что умеет

| Функция | Free | Pro |
|---|---|---|
| Публикация сразу (любые медиа, форматирование, премиум-эмодзи) | ✅ | ✅ |
| Отложенные посты (очередь, отмена, часовой пояс) | ✅ до 15 в очереди | до 1000 |
| Подключённых каналов | 3 | 25 |
| ИИ-рерайт (3 стиля: обычный / короче / ярче) | 5 в сутки | 150 в сутки |
| Нейропостинг: каналов-источников | 2 | 30 |
| Правила автопересылки между своими каналами | 1 | 15 |

Лимиты и цена лежат в `bot/plans.py` и `.env` (`PRO_PRICE_STARS`, `PRO_DAYS`) — меняйте как угодно.

**Как сохраняются премиум-эмодзи.** Если текст не меняется ИИ, пост уходит через `copy_message`:
Telegram копирует сообщение как есть, вместе с форматированием и кастомными эмодзи. Если же текст переписан
нейросетью, он уходит обычным текстом (кастомные эмодзи в нём пропадают, обычные Unicode-эмодзи остаются).

## Быстрый старт (Docker)

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. ```bash
   cp .env.example .env        # впишите BOT_TOKEN
   docker compose up -d --build
   docker compose logs -f ollama-pull   # первый запуск скачивает модель (несколько ГБ)
   ```
3. В Telegram: `/start` → `/channels` → «Добавить канал». Бот должен быть **админом канала с правом
   публикации сообщений**; вы тоже должны быть админом.
4. Пришлите боту любой пост — выберите каналы, при желании нажмите «✨ Переписать», затем «🚀 Сейчас»
   или «⏰ Отложить» (`18:30`, `завтра 09:00`, `12.10 18:30`, `через 2 часа`).

Без Docker: `pip install -r requirements.txt`, установите [Ollama](https://ollama.com), `ollama pull qwen3:4b`,
затем `python -m bot` (нужен свежий Ollama: бот передаёт параметр `think: false`).

### Какую модель взять

`LLM_MODEL` в `.env`: `qwen3:1.7b` — для слабых серверов, `qwen3:4b` — по умолчанию, `qwen3:8b` — лучше
русский язык, нужно около 8 ГБ RAM. Скорость на CPU зависит от железа — замерьте на своём сервере и
подберите `LLM_TIMEOUT`. Ollama обрабатывает запросы по очереди, поэтому при наплыве пользователей рерайт
замедляется; именно поэтому ИИ ограничен дневной квотой, а не безлимитом.

## Нейропостинг: чужие каналы → ваши

`/feeds` → «Добавить источник» → пришлите `@username` публичного канала → отметьте свои каналы-получатели, ИИ-рерайт
(3 стиля) и строку «Источник: @канал». Дальше бот каждые 2 минуты проверяет источник и публикует **только новые**
посты (старые при добавлении не публикуются). Поддерживаются текст, фото, видео, файлы и альбомы до 10 штук.

**Как это работает.** Bot API показывает боту только каналы, где он админ, поэтому чужие каналы читает
отдельный аккаунт-читатель на Telethon. Подключение (один раз, владелец бота):

1. На <https://my.telegram.org> → *API development tools* создайте приложение, возьмите `api_id` и `api_hash`.
2. Впишите в `.env`: `TG_API_ID`, `TG_API_HASH`.
3. Войдите аккаунтом (спросит телефон, код и пароль 2FA) **до** запуска бота:
   - без Docker: `python -m bot.login`
   - Docker: `docker compose run --rm bot python -m bot.login`
4. Запустите бота. В логах не должно быть «Нейропостинг выключен».

**Что нужно знать:**
- Берите **отдельный** аккаунт, не личный: Telegram может ограничить аккаунт, который массово читает каналы.
- Читаются только публичные каналы (с `@username`). Приватные по инвайт-ссылке не поддерживаются.
- Форматирование исходного текста (жирный, ссылки-гиперссылки, премиум-эмодзи) не переносится: бот получает
  чистый текст. Если ИИ выключен, текст публикуется как простой.
- Перепощивание чужих материалов может нарушать авторские права. Строка «Источник» включена по умолчанию, но
  ответственность за контент лежит на пользователях бота: учитывайте это в условиях использования.
- Один раз в цикл бот пишет в Telegram не чаще раза в полторы секунды на источник; много источников у многих
  пользователей упрутся в лимиты аккаунта-читателя. Для масштаба нужны несколько аккаунтов.

## Автопересылка между своими каналами (зеркала)

`/mirrors` → «Новое правило»: выберите канал-источник и каналы-получатели, при желании включите ИИ-рерайт.
Новые посты источника копируются в получатели автоматически; если дневной лимит ИИ исчерпан или модель
недоступна, пост уходит без изменений, а вы получаете предупреждение.

Источник здесь — только ваш канал, где бот админ. Для чужих каналов используйте нейропостинг (`/feeds`).

## Монетизация

Pro продаётся за Telegram Stars (`currency="XTR"`): отдельный платёжный провайдер не нужен. Бот отвечает на
`/paysupport` (Telegram требует эту команду для платных ботов) — укажите `SUPPORT_CONTACT`. Условия вывода
и комиссию Stars смотрите в актуальной документации Telegram. Единственная ощутимая статья расходов —
сервер для модели, поэтому платными сделаны именно ИИ и объёмы.

## Структура

```
bot/
  config.py  plans.py  db.py        # настройки, тарифы, SQLite (stdlib)
  timeparse.py                       # «завтра 09:00», «через 2 часа», часовые пояса
  llm.py                             # рерайт через Ollama + очистка ответа Qwen3
  publisher.py  scheduler.py         # публикация, очередь отложенных постов
  mirror_engine.py                   # автопересылка и квоты ИИ
  feeds.py  telethon_reader.py       # нейропостинг: типы, читатель чужих каналов (Telethon)
  feed_engine.py  login.py           # цикл опроса источников; вход аккаунта-читателя
  handlers/                          # aiogram: common, channels, posting, mirror, feeds, billing
  main.py                            # сборка бота
tests/                               # unittest
Dockerfile  docker-compose.yml  .env.example
```

## Тесты

```bash
python -m unittest discover -s tests -t .
```

123 теста: разбор времени, очистка ответа модели и настоящий HTTP-обмен с поддельным Ollama, БД и лимиты,
публикация, планировщик, зеркала, нейропостинг (читатель с поддельным клиентом Telethon, движок опроса,
альбомы, лимиты, ошибки), а также сквозные сценарии хэндлеров с поддельными объектами Telegram.

## Что проверено, а что нет

Проверено автоматически: вся логика выше (тесты проходят), статический анализ `ruff` и `mypy`.

**Не проверено:** запуск против настоящего Telegram и настоящей Ollama. Код писался в песочнице без доступа
к PyPI, поэтому библиотека aiogram там не была установлена, а хэндлеры тестировались с заглушкой
(`tests/aiogram_stub.py`). Если aiogram установлен, те же тесты автоматически идут с настоящей библиотекой —
запустите их первым делом. Telethon тоже не запускался с настоящим Telegram: читатель проверен на
поддельном клиенте. Отдельно проверьте на тестовых каналах: сохранение премиум-эмодзи при `copy_message`,
оплату Stars и нейропостинг (вход аккаунта, чтение источника, публикацию текста, фото и альбома).

## Известные ограничения

- Альбомы (несколько фото в одном посте) пока не поддерживаются: пришлите по одному файлу.
- Черновики хранятся в памяти и пропадают при перезапуске; отложенные посты и правила лежат в SQLite.
- Отложенный пост ссылается на исходное сообщение в вашем чате с ботом: не удаляйте его до публикации.
- Один процесс и SQLite рассчитаны на тысячи пользователей; дальше нужны Postgres и внешний воркер.
